# Project Charter — EcoMonitor Brasil

## Nome do Projeto
EcoMonitor Brasil — Plataforma Inteligente para Monitoramento de Indicadores Ambientais e Sustentabilidade

## Problema de Negócio
Dados ambientais importantes, como informações relacionadas ao clima, queimadas, desmatamento e outros indicadores de sustentabilidade, encontram-se distribuídos em diferentes fontes públicas. Essa fragmentação dificulta a análise conjunta das informações e o acompanhamento de tendências, riscos e situações críticas.

## Objetivo Geral
Desenvolver uma aplicação interativa capaz de integrar, organizar e apresentar dados ambientais provenientes de fontes públicas, facilitando o acompanhamento de indicadores relacionados à sustentabilidade e às mudanças climáticas.

## Objetivos Específicos
- Integrar diferentes fontes públicas de dados ambientais.
- Organizar e tratar os dados coletados utilizando Python.
- Disponibilizar informações por meio de um dashboard interativo em Streamlit.
- Apresentar indicadores ambientais utilizando tabelas, gráficos e métricas.
- Incorporar, nas etapas futuras, recursos de inteligência artificial generativa para apoiar a interpretação dos dados.

## Escopo do Projeto
O projeto compreenderá a coleta de dados por APIs e outras fontes públicas, processamento e organização dos dados, criação de visualizações interativas e desenvolvimento de uma aplicação em Streamlit.

Nas etapas posteriores, poderão ser incorporados WebScraping, técnicas de aprendizado de máquina e modelos de linguagem de grande escala (LLMs).

## Fora do Escopo Inicial
Nesta primeira etapa, não será realizada a implantação completa de modelos avançados de aprendizado de máquina nem a integração definitiva com LLMs. Esses recursos serão desenvolvidos progressivamente nos próximos TPs.

- Desenvolvedor responsável pelo projeto.

## Principais Entregáveis
- Estrutura organizada do projeto.
- Documentação do projeto.
- Integração com fontes públicas de dados.
- Base de dados tratada.
- Dashboard interativo em Streamlit.
- Visualizações e indicadores ambientais.
- Recursos de análise inteligente desenvolvidos nas etapas posteriores.

## Critérios de Sucesso
O projeto será considerado bem-sucedido caso consiga integrar dados de fontes públicas, apresentar informações de maneira clara e interativa, permitir o acompanhamento de indicadores ambientais e evoluir para a utilização de recursos de inteligência artificial nas etapas posteriores.
